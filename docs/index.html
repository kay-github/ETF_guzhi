评分标准

Value 维度 · 0–12 分

取官方 PE / PB 百分位的较大值，映射到 0–12 档。处于历史低位（百分位接近 0）得满分，高位被压制。

目的：衡量估值便宜程度，避免只看绝对值忽略历史位置。
Pain 维度 · 0–8 分

基于近十年窗口最大回撤，跌幅线性映射到 0–8 分。回撤越深，市场经历的痛苦越多，潜在安全垫越厚。

目的：刻画情绪与风险释放程度，为逆向配置提供依据。
